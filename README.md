# 【ガンコン体験】ゾンビを撃ち抜け！ゾンビバスターズ

迫ってくるゾンビを撃ちまくる、1 回 1 分のガンシューティングです（Windows 版）。

## 遊び方

1. [Releases](https://github.com/EJ516/zombiebusters/releases/latest) から zip をダウンロードして展開する
2. `ZombieBusters.exe` を起動する
   （「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」）

| 操作 | |
|---|---|
| 狙う | マウス |
| 撃つ | 左クリック（押しっぱなしで連射） |
| リロード | 右クリック または R（弾が切れると自動） |
| 一時停止 | Esc |
| 終わる | Alt + F4 |
